# 台本作成工程

動画概要、`work/research/research.md`、`work/research/sources.md` を読み、調査済みの情報だけを用いて `work/script/script.md` を作成してください。

- 動画全体を最大約3分に収める。視聴者に合わせ、専門用語には短い説明を添える。
- 動画の内容を適切に表す短いタイトルを1行だけで `work/script/title.txt` に保存する。ファイル拡張子、改行、パスは含めない。
- Markdownの先頭に、テーマ、想定視聴者、目標尺、総推定秒数を記載する。
- 動画概要に時間の指定がある場合は、見出しや定型表記に限らず自然文から読み取って目標尺にする。時間の幅が指定されている場合は中央の時間を目標にする。
- 時間の明記がない場合は、伝えたい内容の量、視聴者、短く・詳しく等の希望を踏まえて目標尺を決める。判断材料がなければ90秒とする。明記のない場合は原則3分以内に収める。
- 決めた目標尺を秒数だけで `work/script/target-duration.txt` に保存する。台本の冒頭にも同じ目標尺を記載し、発話と無音区間を含む完成動画が目標尺の90〜110%に収まるよう台本の分量と各シーンの推定秒数を調整する。
- 目標尺への調整は、説明に必要なセリフを増やす、冗長なセリフを削る、自然な話し言葉へ書き換える方法で行う。事実の正確さと結論を保ち、読み上げ速度や発話間の無音を尺合わせのために変更する前提で台本を作らない。
- `## Scene 001` のようにシーンを連番で分ける。各シーンに「推定秒数」「ナレーション」「画面で伝えること」を含める。
- ナレーションは自然な話し言葉にし、重要な事実と結論を誇張しない。
- 英字の固有名詞や略語は、ナレーション本文・字幕・画面表示に使う正式な英字表記のまま記載する。VOICEVOXで読み誤りやすい語には、ナレーション本文とは別に読みをカタカナで指定する（例: `GitHub` → `ギットハブ`、`OpenAI` → `オープンエーアイ`）。この読みは音声生成専用であり、字幕や画面表示には使わない。
- 画面の説明は全文字幕ではなく、図解・比較・変化など、理解につながる表現を指定する。

不確実な情報は断定せず、必要なら扱わないでください。
